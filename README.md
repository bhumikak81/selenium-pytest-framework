## Selenium + Pytest Automation Framework (SauceDemo)
This is a Python Selenium automation framework built using Pytest and Page Object Model (POM).It automates end-to-end test flows on SauceDemo, including login, add to cart, and checkout

## Features
1. Page Object Model (POM) → clean & reusable code
2. Cross-Browser Support → Chrome & Firefox (configurable)
3.Config Driven → manage browser, URL, credentials in config.json
4. Pytest Fixtures → WebDriver setup/teardown in conftest.py
5. Reports → generates detailed pytest-html reports

## Scenarios Covered:
1. Valid login
2. Invalid login
3. Add product to cart
4. Checkout flow
